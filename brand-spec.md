# TCG Vault — Brand Spec

## Visual Direction
**Playful / Illustrative**
- Inspired by the bold, high-contrast layout of the Rabbit R1.
- Modern dark theme with vibrant "Mana Purple" accents.

## Palette (OKLch)
- **Background (`--bg`):** `oklch(18% 0.01 280)` — Deep charcoal grey.
- **Surface (`--surface`):** `oklch(24% 0.01 280)` — Elevated grey for cards and sections.
- **Foreground (`--fg`):** `oklch(98% 0.01 280)` — Near-white for primary text.
- **Muted (`--muted`):** `oklch(75% 0.01 280)` — Soft grey for secondary info.
- **Border (`--border`):** `oklch(35% 0.01 280)` — Subtle separators.
- **Accent (`--accent`):** `oklch(70% 0.25 300)` — Electric purple for CTAs and branding.
- **Accent Soft:** `oklch(32% 0.1 300)` — Deep purple for backgrounds.

## Typography
- **Display:** `Inter`, weight 900, tight letter-spacing (-0.05em). Used for primary headings and logo.
- **Body:** `Inter`, weight 400/600, clean system sans-serif.
- **Mono:** `JetBrains Mono` for metadata and technical details.

## Logo & Branding
- **Source Image:** `mpc1t4cl-Diseño-sin-título.png`
- **Header Size:** 120px height.
- **Footer Size:** 180px height.
- **Styling:** `mix-blend-mode: multiply` applied to blend logo background with dark theme (optimized for white backgrounds).

## Layout Posture
- **Hero:** Split-grid with massive typography and illustrative card elements.
- **Radii:** 32px for large containers, 16px for cards and buttons.
- **Spacing:** Generous 80px section padding for a high-end feel.
